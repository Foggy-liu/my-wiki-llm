# 喜剧叙事技巧

## 核心要素

### 1. 预期违背

- 建立预期
- 反转打破
- 意外惊喜

### 2. 夸张放大

- 放大日常细节
- 放大人物特征
- 夸张但不离谱

### 3. 文化梗

- 时代梗
- 地域梗
- 职业梗
- 谐音梗

### 4. 反差萌

- 严肃场合的不严肃
- 高大上的接地气
- 古老与现代的碰撞

## 60秒喜剧结构

```
开场（5秒）: 建立场景或人设
发展（25秒）: 铺垫+埋梗
高潮（25秒）: 连续反转或大爆发
结尾（5秒）: 神转折或金句收尾
```

## 文物喜剧化方向

| 文物 | 喜剧切入点 | 创意方向 |
|------|------------|----------|
| 清明上河图 | 画中人上班 | 古代打工人的一天 |
| 青铜面具 | 表情包 | 文物也开始"社交" |
| 长城 | 游客打卡 | 当古人看到游客自拍 |
| 唐三彩 | 颜色 | 唐朝人就穿这么花哨？ |
