# 剧情叙事技巧

## 核心要素

### 1. 人物塑造

- 鲜明的人物设定
- 成长弧线
- 真实情感

### 2. 冲突构建

- 内在冲突：情感与理智
- 外在冲突：人物与环境
- 关系冲突：爱恨情仇

### 3. 情感节奏

- 铺垫情绪
- 积累爆发
- 余韵回味

### 4. 细节打磨

- 微表情捕捉
- 环境细节
- 道具象征

## 60秒剧情结构

```
开场（5秒）: 人物+情境建立
发展（30秒）: 冲突展开+情感积累
高潮（20秒）: 情感爆发点
结尾（5秒）: 留白+情感余韵
```

|------|----------|----------|
