# 文物IP短视频创作指南

## 核心创作框架

### 1. 素材选择

| 文物类型 | 推荐风格 | 原因 |
|---------|---------|------|
| 青铜器（面具、金杖） | 悬疑/科幻 | 历史神秘感强 |
| 石窟（敦煌、龙门） | 古风/浪漫 | 艺术气息浓厚 |
| 宫廷文物（故宫） | 古风/浪漫 | 皇家文化背景 |
| 唐三彩 | 古风/浪漫/科幻 | 色彩丰富、生活气息 |

### 2. 叙事风格选择

#### 悬疑风格

- 适用文物：青铜面具、玉器
- 开场：神秘氛围 + 悬念抛出
- 发展：逐步揭示文物背后的秘密
- 参考：[[悬疑叙事技巧]]

#### 古风风格

- 适用文物：石窟、唐三彩、宫廷文物
- 开场：空镜头建立氛围
- 发展：意境为先，舒缓节奏
- 参考：[[古风叙事技巧]]

#### 科幻风格

- 适用文物：任何文物均可科幻化
- 创意方向：远古文明、外星接触、时间穿越
- 参考：[[科幻叙事技巧]]

#### 浪漫风格

- 适用文物：宫廷文物、信物类文物
- 情感方向：永恒、守护、传承
- 参考：[[浪漫叙事技巧]]

### 3. 脚本结构（60秒标准）

```
开场（5秒）: 文物特写 + 风格定调
发展（30秒）: 情节展开 + 文物呈现
高潮（20秒）: 核心冲突或情感爆发
结尾（5秒）: 留白 + 引导互动
```

## 文物与风格组合案例

| 文物 | 风格 | 创意方向 |
|------|------|---------|
| 青铜面具 | 悬疑 | 三千年前的祭祀秘密 |
| 青铜面具 | 科幻 | 远古能量源觉醒 |
| 敦煌飞天 | 浪漫 | 反弹琵琶的爱情 |
| 故宫 | 古风 | 琉璃瓦下的誓言 |
| 唐三彩 | 科幻 | 千年后苏醒的俑人 |

## 通用技巧

1. **文物特写**：善用微距镜头展示细节
2. **光影运用**：根据风格选择光影（神秘→暗调，浪漫→暖调）
3. **音效配合**：风格统一，年代感准确
4. **文化准确**：确保服饰、建筑、器物符合朝代特征
