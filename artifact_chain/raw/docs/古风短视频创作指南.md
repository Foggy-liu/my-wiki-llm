## 核心内容

### 古风叙事核心要素

#### 1. 时代背景选择

- **秦汉**：大气磅礴，威严庄重
- **唐宋**：诗词歌赋，风雅俊逸
- **明清**：园林庭院，婉约细腻
- 根据文物朝代选择匹配的时代氛围

#### 2. 画面美学

- **色彩**：青墨、水墨、朱红、黛色
- **构图**：留白、对称、写意
- **光影**：柔和自然，避免现代光源穿帮
- **参考**：中国画、戏曲舞台美学

#### 3. 叙事节奏

- 舒缓悠长，意境为先
- 避免过于紧凑的现代叙事节奏
- 善用空镜头：山水、建筑局部、特写
- 转场可使用：扇面、水墨晕染、镜头推移

#### 4. 音乐与音效

- 古筝、琵琶、古琴、笛箫
- 自然音效：风声、雨声、鸟鸣
- 避免电子音乐和现代音效

### 60秒古风短视频结构

```
开场（5秒）: 空镜头建立氛围（山水/建筑/园林）
发展（30秒）: 人物出场，情节展开
高潮（20秒）: 情感高潮，配乐最强处
结尾（5秒）: 留白收尾，意味深长
```

### 常用表现手法

| 手法 | 说明 | 示例 |
|------|------|------|
| 借景抒情 | 以景物寄托情感 | 雨中孤亭，思念悠长 |
| 意象叠加 | 多个意象组合营造意境 | 明月+孤灯+背影 |
| 对话留白 | 关键对话不说破 | "你还记得..."话音未落 |
| 慢镜头特写 | 强调重要动作或物品 | 手持文物轻抚 |

### 与文物结合的创意方向

1. **敦煌飞天**：反弹琵琶的飞天仙子
2. **故宫**：琉璃瓦下的宫廷故事
3. **青铜面具**：古蜀祭祀的神秘仪式
4. **唐三彩**：俑人复苏的穿越时空
