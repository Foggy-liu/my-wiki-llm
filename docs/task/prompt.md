  1. 史实约束 — 创作内容必须基于真实历史资料                                                                                                 
  2. 创意生成 — 支持业务人员的多样化创意需求

  核心操作流程

  Ingest（消化新资料）
  1. 读取 raw/ 下的源文件
  2. 提取引用、概念、核心论点
  3. 与用户确认重点
  4. 创建/更新 Wiki 页面
  5. 维护交叉引用 [[wikilinks]]
  6. 更新 index.md
  7. 记录到 log.md

  Query（查询资料）
  1. 用户提问
  2. LLM 读取 index.md（理解 Wiki 结构）
  3. LLM 判断需要查询哪些页面
  4. LLM 读取选定页面
  5. 综合回答，标注来源
  6. 记录到 log.md

  Lint（健康检查）
  1. 检测矛盾页面
  2. 检测孤立页面
  3. 检测缺失引用
  4. raw/ 同步检查（文件删除/移动/修改）
  5. 更新 index.md

  ---
  读写分离设计（支持频繁更新）

  用户修改 raw/
      ↓
  变化写入 raw_changes/pending/
      ↓
  定时同步（每 N 分钟）
      ↓
  批量更新 Wiki
      ↓
  Query 使用版本快照，不受更新影响

  ---
  关键约束

  1. Raw 不可修改 — 所有原始资料只读不写
  2. Query 基于 Wiki，不直接读 Raw — 确保查询一致性
  3. 自动创建缺失引用 — Ingest 时 [[wikilink]] 目标不存在则自动创建占位页
  4. 完整日志 — 所有操作记录到 log.md
  5. 矛盾透明 — 资料冲突时显式标注，不掩盖
