**题目一：文物 IP 内容自动化生产链设计与局部实现**

**背景**

公司正在探索“文化 + AI”方向，希望围绕某一类中国文物（如三星堆、敦煌、故宫等，自选），设计一条内容自动化生产链。

业务人员通过对话输入一句创意需求，例如：

“以青铜面具为主角，写一个 60 秒悬疑风短视频脚本。”

系统应能够围绕该需求，完成从资料组织、内容生成到下游 Prompt 对接的一条基础链路。

**任务**

请你完成以下内容：

**设计整体链路框架**  
至少覆盖以下三个环节：

**资料层**：如何组织文物相关资料，使其同时支持史实约束与创意生成

**生成层**：如何基于资料生成脚本，尽量降低脱离资料的随意编造

**对接层**：如何将脚本进一步转化为可供图片或视频生成工具使用的 Prompt

**实现其中一个关键环节**  
从上述链路中任选一个关键模块，完成代码实现或可运行 Demo。  
例如但不限于：

文物资料整理 / 检索模块

基于资料的脚本生成模块

脚本转 Prompt 模块

内容依据引用或溯源模块

**我们重点关注**

你是否能把“内容生产链”拆成清晰可执行的环节

你是否理解“生成结果需要受到资料约束”这一核心问题

你实现的关键模块是否体现工程化思维，而不只是概念描述

**题目二：AI 选址分析工具诊断与优化**

**背景**

现有一个 AI 选址分析工具，已覆盖地址解析、竞品搜索、商圈分析、场地评估、财务测算等能力，但在实际使用中存在若干问题。

**已知问题**

网络搜索“VR 大空间”“XR 体验馆”等关键词时，经常无法召回有效竞品

商圈客流量主要来自新闻信息，可信度不足

上传 CAD 截图或平面图后，系统无法自动给出有效场地分析

财务测算过程不透明，且结果无法导出为可编辑表格

**任务**

请你完成以下内容：

**对上述问题做系统性拆解**

分析问题根因

说明哪些问题适合用 AI 解决，哪些更适合通过规则、模板、数据治理或流程设计解决

**设计一版优化方案**

给出整体架构或流程优化思路

说明关键模块如何协作

**从中任选两个问题，完成关键模块实现**  
可为代码实现或可运行 Demo 或具体代码设计方案  
例如但不限于：

竞品数据收集策略

客流估算逻辑与信源爬取

平面图信息抽取流程

财务模板计算与导出模块

**我们重点关注**

你是否能准确识别问题的真实根因

你是否能提出现实可落地的优化方案，而不是只讲概念

你是否具备把复杂问题收敛为关键工程模块的能力
